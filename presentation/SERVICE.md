# 서비스 설명서

> IR deck 목차를 잡기 위한 기준 문서. 기획 논의(원본 노션)와 현재 구현 상태를 한 곳에 정리했다.
> 코드와 어긋나는 내용이 생기면 이 문서를 먼저 고친다.

## 1. 한 줄 정의

**내가 실제로 가진 화장품만으로, 내 피부 고민과 쓸 수 있는 시간에 맞춘 스킨케어 루틴을 AI가 만들어 주고 그대로 따라 하게 해 주는 앱.**

## 2. 왜 이걸 만드나 (문제)

스킨케어는 "무엇을 살까"보다 "가진 걸 어떤 순서로, 얼마나, 언제 쓰느냐"에서 실패한다.

1. **정보는 넘치는데 내 것이 아니다.** 유튜브·블로그 루틴은 그 사람이 가진 제품 기준이다. 내 화장대에 없는 제품이 절반이다.
2. **성분 충돌을 개인이 판단할 수 없다.** 레티놀과 AHA를 같은 날 밤에 쓰면 안 된다는 걸 알려면 성분표를 읽고 상호작용을 알아야 한다.
3. **시간이 없다.** 아침 3분 쓸 수 있는 사람에게 7단계 루틴은 지키지 못할 계획이다.
4. **컨디션에 따라 루틴이 달라져야 한다.** 생리 기간처럼 피부가 예민해지는 시기엔 평소 루틴(비타민 C·레티놀)을 그대로 쓰면 안 된다.

## 3. 해결 방식

**제품 등록 → 루틴 생성 → 루틴 수행**의 3단계. 각 단계에 LLM이 한 번씩 개입한다.

| 단계          | 사용자가 하는 일                        | AI가 하는 일                                         |
| ------------- | --------------------------------------- | ---------------------------------------------------- |
| 제품 등록     | 제품명(필수) + 용량·회사·성분표 사진    | 성분 목록 추출 + 카테고리 분류 + 단독 사용 주의사항  |
| 루틴 생성     | 피부 고민 + 투자 가능 시간              | 보유 제품만으로 아침/저녁 루틴 생성(순서·시간·주의)  |
| 루틴 수행     | 단계별로 따라 하기                      | (생성 시점에 만든) 사용법·소요 시간·전문가 팁 제공   |

### 핵심 설계 결정

- **상품 검색 API를 쓰지 않는다.** 네이버 쇼핑 검색 API는 신규 발급이 막혔고 카카오엔 상품 카탈로그가 없다. 대신 **성분표 사진을 그대로 LLM에 넘겨** 제품을 등록한다. 특정 상품 DB에 의존하지 않으므로 단종·해외 제품·소분 제품도 등록된다.
- **없는 제품을 추천하지 않는다.** 루틴 생성 프롬프트는 "제공된 products만 사용"을 규칙으로 강제한다. 커머스가 아니라 **가진 것을 잘 쓰게 하는 도구**다.
- **시간 예산을 지킨다.** 사용자가 말한 아침/저녁 가용 시간을 넘지 않도록 단계 수를 조절한다.
- **성분을 지어내지 않는다.** 이미지가 없고 공개 정보로 특정되지 않으면 성분을 빈 배열로 반환하게 한다. 신뢰가 깨지는 지점을 프롬프트 레벨에서 막았다.
- **의학적 진단을 하지 않는다.** 증상이 심하면 피부과 상담 권고 문구를 넣도록 규칙화했다. 규제 리스크 회피.

## 4. 화면 구성 (4탭)

| 탭         | 담는 것                                                              |
| ---------- | -------------------------------------------------------------------- |
| **홈**     | 현재 시각, 루틴 시작 버튼                                            |
| **스캔**   | 제품 등록 — 이름(필수) / 용량 mL(선택) / 회사(선택) / 성분표 사진(선택) |
| **루틴**   | 이번 주 진행 상황, 모닝·나이트 토글, 루틴 리스트, 루틴 시작 버튼     |
| **프로필** | 기록, 저장한 화장품 리스트                                           |

## 5. 사용자 플로우

### 5-1. 제품 등록

1. 스캔 화면에서 제품 정보를 입력한다(이름만 필수).
2. LLM이 성분표 사진 또는 제품명·회사를 근거로 **제품명 / 카테고리 / 성분 목록**을 뽑아 저장한다.
3. 같은 정보로 **단독 사용 시 주의사항**(최대 6개)을 생성해 함께 저장한다.

### 5-2. 루틴 생성

1. 입력: 피부 고민(text), 아침·저녁 투자 가능 시간(text), 등록된 제품 목록.
2. LLM이 아침/저녁 루틴을 생성한다. 각 단계마다 **루틴 이름 · 예상 소요 시간(초) · 사용 제품 · 사용 방법 · 팁 · 주의사항**.
3. 규칙: 일반 스킨케어 순서 준수, 한 단계 = 한 제품 원칙(이중 세안 예외), 성분 충돌 회피, 필수 단계 제품이 없으면 생략하고 안내.
4. 생성된 루틴과 총 예상 시간을 보여준다. (수정 기능은 추후)

### 5-3. 루틴 수행

1. 제품 사용 순서를 단계별로 보여준다.
2. 각 단계에서 사용 방법·타이머·전문가 팁·주의사항을 띄우고 다음 단계로 넘긴다.
3. 종료 시 기록을 저장한다. (기록 저장은 미구현)

## 6. AI 파이프라인 (프롬프트 3종)

모두 **JSON only** 출력. 코드블록·설명 텍스트 금지.

| 프롬프트           | 입력                                     | 출력                                             |
| ------------------ | ---------------------------------------- | ------------------------------------------------ |
| 제품 성분 추출     | 제품명, 용량, 회사, 성분표 이미지(base64) | `{ product_name, category, ingredients[] }`      |
| 스킨케어 루틴 작성 | 고민, 가용 시간(아침/저녁), 보유 제품 목록 | `{ morning[], evening[] }` (단계별 상세 포함)    |
| 제품 주의 사항     | 제품명, 카테고리, 성분 목록              | `{ warning[] }` (최대 6개)                       |

각 프롬프트에 **환각 억제 규칙**(추측 금지, 원문 표기 유지, 근거 없는 위험성 서술 금지)과 **안전 규칙**(진단 금지, 피부과 권고)이 들어 있다. 프롬프트 전문은 기획 원문 참고.

## 7. 차별점

1. **가진 제품 기반.** 추천 커머스가 아니라 보유 재고를 최적 배치하는 도구.
2. **상품 DB 없이 등록 가능.** 성분표 사진 → LLM. 검색 API 종속이 없다.
3. **시간 예산 준수.** 지킬 수 있는 분량만 만든다.
4. **상황별 루틴.** 생리 주기처럼 피부가 달라지는 시기용 루틴을 따로 둔다(자극 성분 제외 버전).
5. **성분 충돌 경고.** 등록된 성분 목록을 근거로 같은 루틴에 넣지 않고, 이유를 알려준다.

## 8. 현재 구현 상태 (프론트)

Next.js 16 App Router · React 19 · CSS Modules. **백엔드/LLM 연동 전이라 데이터는 전부 시드 상수다.**

| 화면                        | 상태                                                                    |
| --------------------------- | ----------------------------------------------------------------------- |
| 홈 `/`                      | 현재 시각, 루틴 시작 CTA, 피부 점수·다음 단계·성분 알림 카드 (목업 데이터) |
| 스캔 `/scan`                | 제품 검색 + 인기 제품 + 카메라 진입. **등록 폼(이름·용량·회사·사진)은 미구현** |
| 루틴 `/routine`             | 이번 주 진행 상황, 루틴 카드 목록(펼치면 단계 요약 + 시작/완료 버튼)     |
| 루틴 수행 `/routine/[id]/[step]` | 단계별 사진 자리·타이머·사용법 체크리스트·전문가 팁·이전/다음            |
| 프로필 `/profile`           | 피부 프로필, AI 분석 리포트, 내 선반(저장한 화장품) — 전부 목업          |

**미구현**: 백엔드 API 전체, LLM 호출 3종, 제품 등록 폼·카메라 OCR 저장, 루틴 생성 입력 화면, 완료 기록 영속화(현재 새로고침하면 초기화), 로그인(의도적으로 범위 밖).
