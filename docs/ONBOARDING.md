## 0. 제일 먼저 — 보안 훅 설치 ⛔

**이 저장소는 퍼블릭이다.** 비밀번호·서버 주소가 한 번 커밋되면 히스토리에 남아 지우기 어렵다.
clone 직후 **반드시** 아래를 실행한다. **안 하면 훅이 아예 돌지 않는다.**

```bash
git config core.hooksPath .githooks
```

이 훅이 커밋 시점에 잡는 것: `.env` 파일 · 자격 증명 패턴 · **공인 IP 주소**.
오탐이면 `.githooks/pre-commit` 의 패턴을 고친다. **`--no-verify` 로 넘기지 말 것.**

절대 커밋하면 안 되는 것:

| 금지                        | 대신                                               |
| --------------------------- | -------------------------------------------------- |
| 서버 IP·도메인·포트 목록    | 로컬 `~/.ssh/config`, `.env.local` 에만            |
| 비밀번호·토큰·API 키·`.pem` | `.env.local` (커밋 안 됨). `.env.example` 은 빈 값 |
| `C:\Users\<이름>\…` 경로    | `~` 나 상대 경로                                   |
| 서버에 뭐가 돌고 있는지     | 안 쓴다. 정찰 정보다                               |

## 1. 실행

```bash
npm ci                       # package-lock 기준 설치 (npm install 아님)
cp .env.example .env.local   # PowerShell: Copy-Item .env.example .env.local
npm run dev                  # http://localhost:3000
```

Node는 **24 LTS**. `.nvmrc` 가 있으니 `nvm use` 로 맞춘다.

`.env.local` 은 값을 비워도 화면은 뜬다. DB·AI 를 붙일 때만 채우면 된다(아래 4·5번).

## 2. 이 앱이 뭔지

**스킨케어 루틴 앱**이다. (저장소 이름의 "Animal League" 는 초기 프로젝트명이 남은 것이다.)

1. **제품 등록** — 성분표를 찍으면 AI가 성분을 뽑아 준다
2. **루틴 생성** — 피부 고민 + 가용 시간 + 보유 제품 → AI가 아침/저녁 루틴을 짠다
3. **루틴 수행** — 단계별 안내와 타이머
4. **기록** — 수행 이력에서 주간 달성률을 계산한다

## 4. AI 기능을 쓰려면

`/api/ai/*` 는 외부 API 가 아니라 **각자 PC의 `claude` CLI(헤드리스)** 를 실행한다.

- `claude` 가 PATH 에 있어야 한다. 없으면 `.env.local` 에 `CLAUDE_BIN=<경로>`.
- **각자의 Claude 구독으로 차감된다.** 루틴 생성 1회에 **약 90초** 걸린다(정상이다).
- ⛔ `ANTHROPIC_API_KEY` 를 설정하지 말 것 — 구독 대신 **종량 과금**으로 빠진다.

CLI 가 없어도 AI 를 안 쓰는 화면은 전부 정상 동작한다.

---

## 5. 서버 DB 에 붙으려면

DB 는 서버에 떠 있고 **인터넷에 열려 있지 않다.** SSH 터널로만 붙는다.

```bash
ssh -L 3308:127.0.0.1:3308 <서버alias>   # 이 창은 켜 둔다
```

**SSH 키와 DB 접속 정보는 이 저장소에 없다.** 팀 채널로 따로 받아서 `.env.local` 에 넣는다.
아직 앱 코드가 DB 를 쓰지 않으므로(Step 3 미착수) **당장은 없어도 개발할 수 있다.**

## 6. 코드 규칙 — 자주 틀리는 것만

- ⛔ **Tailwind 금지.** 설치돼 있지도 않다. 스타일은 **CSS Modules** (`Xxx.module.css`).
  다른 프로젝트에서 코드를 가져올 때 `className="flex gap-4"` 가 딸려 오기 쉽다.
- 색은 `globals.css` 의 CSS 변수(`var(--background)`)를 쓴다. **hex 하드코딩 금지.**
- `src/app/**` 은 **기본이 서버 컴포넌트**다. `useState`·이벤트 핸들러를 쓰면 `"use client"` 가
  필요하고, 그 경계는 **가능한 한 아래(leaf)로** 내린다.
- `any` 금지. 모르면 `unknown` 으로 받고 좁힌다.
- 주석은 한글로, **무엇이 아니라 왜**를 쓴다.

**커밋 전에 반드시:**

```bash
npm run check      # 타입 + 린트 + 포맷. CI 가 이걸 그대로 돌린다
```

`main` 에 직접 커밋하지 않는다. 브랜치를 파고 PR 을 올린다.
