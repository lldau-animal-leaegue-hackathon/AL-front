      그래서 주석이 말하는 "숫자·영문 토큰으로 느슨히 본다"가 **실제로는 일어나지 않는다** — 이름 전체가 토큰 1개가 된다.

      즉 **결함이 둘**이다: ⓐ 평소에는 어댑터가 아무것도 못 찾아 사실상 죽어 있고(조용한 기능 부재),
      ⓑ 구두점으로 분리된 파편(`100ml` 같은 용량·모델번호)이 생기면 **아무 제품에나 걸려 엉뚱한 성분을 반환**한다.
      → 수정: ① 토큰화를 `normalize` **이전**(공백 유지 상태)에 하고, ② 매칭 대상을 URL 전체가 아니라 `/products/` 이후 슬러그로 한정,
      ③ 용량·단위 토큰(`\d+ml`, `\d+g`)을 매칭에서 제외, ④ **최소한 상세 HTML 의 `title`/`og:title` 과 요청 제품명을 대조한 뒤에만 성분을 반환**한다.
      ④ 없이 ①~③만 하면 여전히 "그럴듯하게 틀린 성분"이 나온다.

### M3 실측 — 현재 토큰화가 무엇을 만드는가

`normalize()` 가 공백을 지운 **뒤에** `/[가-힣a-z0-9]{2,}/g` 로 토큰을 뽑으므로, 구두점이 없으면 이름 전체가 토큰 1개다.

```
"원더 세라마이드 모찌 토너"         → ["원더세라마이드모찌토너"]           → 매칭 없음
"AC 컨트롤 토너"                    → ["ac컨트롤토너"]                     → 매칭 없음
"원더 세라마이드 모찌 토너 - 100ml"  → ["원더세라마이드모찌토너", "100ml"]  → master-lab-hyaluronic-acid-100ml ❌
```

마지막 줄이 실해다 — **용량 파편 하나로 전혀 다른 제품의 전성분**이 이 제품의 것으로 저장된다.
